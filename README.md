# AI-Powered Performance Test Case Generator

This repository contains the source code for the AI-Powered Performance Test Case Generator, as described in the Business Requirements Document.

## Project Structure

The repository is organized into the following modules:

- **/frontend**: Contains the React.js user interface.
- **/backend**: Contains the backend service (FastAPI) that exposes the core functionality via a REST API.
- **/ai-engine**: Contains the core Python-based AI analysis engine responsible for crawling web applications and detecting components.
- **/tests**: Contains the unit and integration tests for all modules.
